Request for Proposal (RFP)

Web Application Development for “Vendor Onboarding & Compliance Portal”**

RFP Title: Vendor Onboarding & Compliance Portal
Issued By: SreeRam Industries Pvt. Ltd.
Issue Date: 18-Nov-2025
RFP Reference: SRIPL/RFP/2025/112

1. Introduction

SreeRam Industries Pvt. Ltd. (SRIPL), a manufacturing and supply-chain company based in Chennai, seeks proposals from qualified software development firms to design and develop a Vendor Onboarding & Compliance Portal (VOCP).
This platform will streamline vendor registration, document verification, performance scoring, and compliance tracking.

2. Project Overview

The current onboarding process is manual and involves email exchanges and multiple Excel sheets.
The new web application will:

Automate vendor registration and approvals

Provide a central compliance dashboard

Enable document uploads and validation

Maintain an audit trail for all interactions

Generate monthly compliance & performance reports

The system must be responsive, secure, and scalable to support 3,000+ vendors and 200+ SRIPL staff.

3. Scope of Work
3.1 Functional Requirements
A. User Management

Admin, Compliance Officer, Procurement Manager, Vendor roles

Two-factor authentication for Admin & Compliance Officers

Activity logging (login, data changes, approvals)

B. Vendor Onboarding

Vendor self-registration form

Uploads: PAN, GST, MSME Certificate, Cancelled Cheque, ISO Certifications

Auto-validation for PAN (checksum), GST number (structure check)

Procurement Manager review & approval workflow

C. Compliance Module

Annual compliance submission (safety compliance, ISO updates, financial reports)

Automated reminders (email + SMS)

Compliance scoring (0–100) based on submitted documents

D. Performance Module

Monthly performance submission

Metrics tracked: Delivery Timeliness (%), Quality Score, Rejection Rate

Automatic trend charts for last 12 months

E. Reports

Vendor master report (Excel/PDF)

Compliance overdue report

Performance trend reports

Exportable dashboards

F. Notifications

Vendor registration confirmation

Document rejection with comments

Compliance due reminders (7 days, 3 days, 1 day)

3.2 Non-Functional Requirements

Performance:
Must support 500 concurrent vendor logins.

Security:
SSL/TLS, AES-256 encrypted storage for sensitive documents, OWASP Top 10 compliance.

Scalability:
Should support 10,000 vendors in future phases.

Tech Stack Preference:

Backend: Spring Boot 3.x

Frontend: React 18 + Material UI

Database: PostgreSQL 15

Hosting: AWS (ECS Fargate + RDS + S3)

Availability:
99.5% uptime.

Audit:
All CRUD actions must be logged with timestamp, user, and IP.
